# Omitted Archive References

Selected historical governance documents refer to a larger private archive.
Their original linked filenames remain visible, but links to documents not
included in this release point here. This is a PUBLIC_ADAPTATION of navigation
only; it is not a claim that the omitted contracts or capabilities are supplied.

The source index records the original archive checksum and adapted checksum.
The public status matrix, not a historical contract's aspirations, defines what
this subset actually implements. Omitted references include the original
Constitution, execution-workflow review/specification, capability registry,
portfolio capability/persistence specifications, and earlier market-data,
adjustment, provider, cache, readiness and data-platform contracts.

No data payload or historical research result is available through these links.
